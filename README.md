## Fintech Guard 

Банковский движок с системой фрод-мониторинга. Переводы между счетами, проверка баланса, защита от частых операций, аудит-лог всех попыток.

 # Описание

Fintech Guard — это симулятор ядра платёжной системы. Он обрабатывает переводы между пользователями и автоматически блокирует подозрительную активность.

 # Возможности

- Перевод денег между пользователями.
- Проверка активности счёта (активен / заблокирован).
- Проверка достаточности средств.
- Фрод-мониторинг: блокировка аккаунта при 3+ успешных переводах за последние 30 секунд.
- Атомарность транзакций (деньги гарантированно списываются у одного и начисляются другому).
- Аудит-лог (каждая попытка перевода, включая отклонённые, записывается в базу данных со статусом rejected).
- Хранение данных в реляционной SQLite (данные не теряются после перезапуска).

# Стек технологий

- Python 3 (ООП, чистая бизнес-логика)
- SQLite3 (работа со связанными таблицами, Foreign Keys, агрегатные функции)
- Datetime API (анализ времени транзакций)
